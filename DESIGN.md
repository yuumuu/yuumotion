# Design

## Visual Theme & Register
- **Theme**: Light & Dark mode adaptive, calm pastel palette with crisp 1px borders.
- **Primary Color**: Violet / Purple (`#7C3AED` light, `#8B5CF6` dark).

## Typography
- **Font Stack**: System sans-serif (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`).
- **Code / Shortcuts**: Monospaced font (`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas`).

## Surfaces & Borders
- **Border Radius**: `rounded-xl` (12px) for cards and modals, `rounded-lg` (8px) for buttons and inputs.
- **Borders**: 1px solid `border-appflowy-border` (`#E5E7EB`) in light mode, `border-appflowy-darkBorder` (`#334155`) in dark mode.
- **Surfaces**: Clean neutral card backgrounds (`bg-appflowy-surface` / `bg-appflowy-darkSurface`).

## Component System
- Reusable UI kit in `src/components/ui/`: `Button`, `Input`, `Textarea`, `Checkbox`, `Switch`, `Badge`, `Kbd`, `Separator`, `Dialog`, `Tabs`, `Toast`, `TagPicker`, `AttachmentCard`.
