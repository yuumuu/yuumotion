# Product

## Register
product

## Users & Purpose
- **Users**: Software engineers, product managers, independent creators, and teams managing sprints, documentation, and agile workflows.
- **Context**: Working extensively on laptop/desktop screens during daily planning, standups, sprint tracking, and writing specifications.
- **Primary Job**: Organize tasks and ideas across multiple visual paradigms (Kanban, Calendar, Gantt, Database Table, Notion-like Standalone Docs) with zero server lock-in and offline-first capabilities.

## Brand & Personality
- **Aesthetic**: Calm, precise, focused.
- **References**:
  - **AppFlowy**: Calm pastel color palette, breathable spacing, Notion-like slash document experience.
  - **Linear**: 1px sharp borders, keyboard-first navigability (`Kbd` hints), instant tactile feedback.
- **Anti-References**: Generic loud SaaS cards, saturated dark gradients, cluttered multi-colored badges, unnecessary decoration.

## Strategic Design Principles
1. **Calm Clarity**: Visual hierarchy prioritizes user content above UI chrome.
2. **Keyboard First**: Every frequent operation reachable via keyboard shortcuts (`/` for global search, `Esc` for modal dismissal, Enter/Space for cards).
3. **Tactile Feedback**: Subtle micro-interactions (drag tilt, active depression, contextual toasts) without disruptive layout shift.
4. **RBAC Guardrails**: Respect Viewer roles with strict read-only lockouts.

## Accessibility
- WCAG AA compliance for color contrast (>= 4.5:1 text, >= 3:1 graphical controls).
- Obvious `focus-visible:ring-2` focus rings for keyboard navigation.
- Smooth transitions respecting user motion preferences.
